# Himno Nacional Mexicano en La Filandria

Arreglo pentatónico aproximado (Jaime Nunó, dominio público), instrumento sin modificar: solo los nueve hilos; Si♭/Mi se aproximan al hilo más cercano. 7 secciones (intro, coro, estrofa I, coro) renderizadas por separado y unidas con fundido. ~2:33.

- `arrange.py` genera `himno_filandria_score.json` y el WAV
- `make_video.sh` arma el MP4 1920x1080 desde `thumb.jpg` + audio
- WAV y MP4 en el release `himno-mexicano-v1`
