# La Filandria

Instrumento inventado: nueve hilos de vidrio soplado, una membrana ahumada y una hendidura en madera de olivo negro. Se toca con un arco de crin guardado en cobre.

**Marea corta** — 10 segundos. Escala de marea (pentatónica menor de re, afinada a mano).
