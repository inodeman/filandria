# YYZ (Rush): La Filandria cromática, v2

Cover instrumental de "YYZ" (Lee/Peart, Moving Pictures, 1981), tocado con los hilos cromáticos de La Filandria. Es un solo render de 3:19 a 140 negras por minuto. La intro en Morse va en 10/8. El bajo dobla el riff una octava abajo y la membrana sigue la armonía (F#/C, F#, A, B, C).

Referencia de notas: la tablatura de guitarra de C. D. Bruce (rev. 04, 2002) en https://www.chords-and-tabs.net/song/name/rush-yyz-4 y la tablatura de bajo de https://www.basscamera.com/rush/yyz.

```bash
python render_yyz_v2.py   # yyz_v2_score.json + yyz_v2.wav (FILANDRIA=ruta al repo)
./make_video.sh           # MP4 1920x1080 con background.jpg, recortado al audio
```
